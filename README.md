# 🏛️ Skilling Centre AI Monitoring & Discrepancy System

An AI-driven video analytics solution designed for automated headcount verification, infrastructure auditing, and discrepancy detection in skilling centres.

## 🚀 Features
- **Aggregate Headcount Detection:** Privacy-preserving person counting without biometric facial recognition storage.
- **Infrastructure Asset Auditing:** Detects chairs, benches, and classroom assets.
- **Automated Discrepancy Flagging:** Real-time variance analysis against portal attendance records with threshold alert triggers (>10%).
- **Interactive Streamlit Web Dashboard:** Simple interface for live video/image audit runs and report generation.

## 🛠️ Tech Stack
- **Model:** Ultralytics YOLOv8 (Custom Trained)
- **Frontend/App Framework:** Streamlit
- **Image Processing:** OpenCV, Pillow, NumPy
